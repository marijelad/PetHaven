# PetHaven — Premium Pet Store Demo

PetHaven is a multi-page static e-commerce portfolio project built with HTML, CSS and vanilla JavaScript. It is designed to deploy directly to GitHub Pages.

## Highlights
- 32 HTML pages
- Responsive navigation and layouts
- Product category pages and 8 individual product pages
- Interactive shop filters
- LocalStorage cart and wishlist
- Demo checkout and order status flow
- FAQ interactions and scroll reveal animations
- Local SVG artwork (no external image dependency)
- Accessibility-minded semantic structure

## Run locally
Open `index.html` in a browser, or serve the folder using any simple static server.

## GitHub Pages
Push the contents to a public repository, then enable GitHub Pages from the repository settings using the root branch/folder.

## Important
This is a portfolio/demo storefront. It does not include a real backend, authentication, payment processing, order fulfillment or live inventory.
